# HA Quick Actions — полное описание программы

**HA Quick Actions** — настольное приложение для Windows (и других ОС с Python), которое подключается к **Home Assistant** по REST API и даёт быстрый доступ к выбранным действиям (сервисам) и отображению состояния датчиков в одном окне.

Исходный код: `main.py`. Рядом с программой (или с `main.py` при запуске из исходников) должен лежать файл **`config.json`**. Образец настроек — **`config.example.json`**.

---

## Назначение

- Вызывать сервисы Home Assistant одним нажатием кнопки (включить свет, запустить сценарий, открыть шторы и т.д.).
- Показывать на главном окне **показания** выбранных сущностей (температура, погода и др.) с периодическим обновлением.
- Работать без браузера: достаточно URL сервера и **долгоживущего токена** (Long-Lived Access Token) из профиля пользователя HA.

---

## Системные требования

### Запуск из исходников

- **Python** 3.10+ (рекомендуется актуальная ветка 3.x).
- Установленные зависимости из `requirements.txt`:
  - `requests` — HTTP-запросы к API Home Assistant;
  - `pystray`, `Pillow` — иконка в системном трее (опционально; при отсутствии пакетов трей отключается).

Команда установки:

```text
pip install -r requirements.txt
```

Запуск:

```text
python main.py
```

### Сборка в один EXE

Скрипт **`build_exe.ps1`** (PowerShell) вызывает PyInstaller и собирает один файл **`HA-Quick-Actions.exe`**.

- По умолчанию результат в папке **`dist\`**.
- Если старый `HA-Quick-Actions.exe` **занят** (программа запущена), сборка может пойти в **`dist_rebuild\`** — см. сообщения скрипта.
- Для уменьшения размера onefile скрипт не использует `--collect-all pystray`, задаёт исключения лишних пакетов и **`--optimize 2`**; ориентир — **до ~25 МБ** на типичной установке Python 3.11–3.14.

Перед пересборкой закройте запущенную копию приложения, если нужна именно папка `dist\`.

## Где лежит конфигурация

- **Запуск из .exe:** каталог, в котором находится исполняемый файл — там же ищется `config.json`.
- **Запуск `python main.py`:** каталог с файлом `main.py`.

Через меню **«Файл → Открыть папку с config.json»** можно открыть эту папку в проводнике.

При первом запуске, если `config.json` нет, программа создаёт его либо из **`config.example.json`** (если он есть рядом), либо из встроенного шаблона.

## Подключение к Home Assistant

**Меню: Файл → Подключение…**

- **URL** — адрес сервера, например `https://192.168.1.10:8123` (без лишнего пути; для API используется корень хоста).
- **Long-Lived Access Token** — токен из HA: Профиль → внизу «Создать токен».
- **Проверка SSL** — снимите галочку только если используете самоподписанный HTTPS и осознаёте риски.

Кнопка **«Проверить»** отправляет запрос к API и сообщает об успехе или ошибке.

## Кнопки действий

### Главное окно

- Кнопки сгруппированы по **вкладкам** (`button_tabs` в `config.json`).
- Для каждой вкладки задаётся свой набор кнопок; каждая кнопка вызывает **domain**, **service** и при необходимости **service_data** (в том числе `entity_id`).

### Редактор кнопок

**Меню: Файл → Редактор кнопок…**

- Создание, переименование, удаление и порядок **вкладок**.
- На выбранной вкладке — список кнопок: добавить, изменить, удалить, вверх/вниз.
- Окно добавления/редактирования кнопки позволяет выбрать сущность из списка состояний HA и подставить домен/сервис из реестра сервисов.

### Внешний вид кнопок (блок в редакторе)

Параметры сохраняются в **`config.json` → секция `ui`**:

| Параметр | Смысл |
|----------|--------|
| `button_font_size` | Размер шрифта на кнопках |
| `button_pad_x`, `button_pad_y` | Внутренние отступы кнопок |
| `columns` | Число колонок сетки кнопок на вкладке |
| `buttons_per_page` | Лимит кнопок на одной «странице» внутри вкладки; **0** — показать все; иначе кнопки «Назад / Вперёд» |

Для обратной совместимости список **`buttons`** в конфиге дублирует кнопки **первой** вкладки (его может заполнять программа при сохранении).

## Панель показаний (датчики)

### Назначение

В верхней части окна выводятся выбранные **сущности** и их текущие значения (с учётом единиц измерения из атрибутов HA, если есть).

### Сворачивание

Кнопка **«Свернуть / Развернуть»** скрывает или показывает блок показаний. Состояние запоминается в **`ui.sensor_panel_collapsed`**. В свёрнутом виде опрос датчиков не выполняется.

### Вкладки и оформление

Данные задаются в **`sensor_tabs`** — массив вкладок. У каждой вкладки:

| Поле | Описание |
|------|-----------|
| `title` | Заголовок вкладки |
| `sensors` | Список датчиков: строка `entity_id` или объект с полями `entity_id`, `label`/`name`, `icon` |
| `columns` | Сколько датчиков **в ряд** (сетка), от 1 до 8 |
| `item_layout` | **`row`** — в строку: иконка, имя, значение; **`column`** — в столбик внутри ячейки. В JSON допускаются синонимы вроде `vertical` для столбика |
| `icon_size` | Размер шрифта области иконки (пт), 8–36 |
| `label_font_size` | Размер подписи (пт), 7–20 |
| `value_font_size` | Размер значения (пт), 7–22 |
| `label_width_chars` | Ширина поля имени в символах, 4–48 |

Интервал опроса всех датчиков — **`sensor_refresh_seconds`** (секунды, в разумных пределах).

### Редактор датчиков

**Меню: Файл → Датчики на главной…**

- Управление **вкладками** (как у кнопок).
- Для вкладки — настройки сетки и шрифтов.
- Список сущностей на вкладке: добавление из каталога HA, имя и иконка, порядок строк.

Поле **`sensor_panel`** в конфиге — устаревший плоский список; при отсутствии `sensor_tabs` программа создаёт одну вкладку из `sensor_panel`. При сохранении из редактора **`sensor_panel`** синхронизируется с датчиками **первой** вкладки.

## Трей и закрытие окна

Если установлены **pystray** и **Pillow**:

- **«Сворачивать в трей при закрытии окна»** — крестик прячет окно, приложение остаётся в трее.
- **«Запускать свёрнуто в трей»** — при старте окно сразу в трей.
- В трее: показать окно, выход.

На Windows в меню «Файл» может быть пункт **автозапуска** (реестр), если эта функция включена в сборке.

## Структура `config.json` (обзор)

| Ключ | Назначение |
|------|------------|
| `ha_url` | URL Home Assistant |
| `ha_token` | Токен доступа |
| `verify_ssl` | Проверка SSL |
| `button_tabs` | Вкладки и кнопки |
| `buttons` | Дубли первой вкладки кнопок (совместимость) |
| `sensor_tabs` | Вкладки датчиков и их оформление |
| `sensor_panel` | Дубли первой вкладки датчиков / миграция |
| `sensor_refresh_seconds` | Период обновления показаний |
| `ui` | Внешний вид кнопок, сворачивание панели датчиков |
| `close_to_tray`, `start_minimized` | Поведение при закрытии и запуске |

Полный пример см. в **`config.example.json`**.

---

## Ограничения и замечания

- Приложение использует **публичный REST API** Home Assistant; сущности и сервисы должны быть доступны тому пользователю, от имени которого выдан токен.
- Ошибки сети и ответы сервера показываются в строке состояния окна и в диалогах при сбоях вызова сервиса.
- Иконки в стиле `mdi:…` на панели отображаются в виде короткого текстового ярлыка (как подсказка), эмодзи показываются как есть, если шрифт их поддерживает.
