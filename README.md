# HA Quick Actions

Настольное приложение для **Home Assistant** (REST API): быстрые кнопки вызова сервисов и панель показаний датчиков в одном окне.

Исходный код: `main.py`. Рядом должны лежать **`config.json`** и при необходимости **`config.example.json`**.

---

## Назначение

- Вызывать сервисы Home Assistant одним нажатием кнопки (включить свет, запустить сценарий, открыть шторы и т.д.).
- Показывать на главном окне **показания** выбранных сущностей (температура, погода и др.) с периодическим обновлением.
- Работать без браузера: достаточно URL сервера и **долгоживущего токена** (Long-Lived Access Token) из профиля пользователя HA.

---

## Системные требования

### Запуск из исходников

- **Python** 3.10+ (рекомендуется актуальная ветка 3.x).
- Зависимости из `requirements.txt`:
  - `requests` — HTTP к API Home Assistant;
  - `pystray`, `Pillow` — трей (опционально; без них трей отключён).

```bash
pip install -r requirements.txt
python main.py
```

### Сборка в один EXE

Скрипт **`build_exe.ps1`** собирает **`HA-Quick-Actions.exe`** (PyInstaller).

- Обычно результат: **`dist\HA-Quick-Actions.exe`**.
- Если файл занят запущенной программой — сборка может уйти в **`dist_rebuild\`** (см. вывод скрипта).
- Сборка «урезанная»: без лишнего `collect-all`, исключены тяжёлые лишние модули (например numpy), bytecode `--optimize 2` — типичный размер одного exe **около 25 МБ и меньше** (зависит от версии Python и окружения).

## Конфигурация

- **Запуск из .exe:** `config.json` в папке с исполняемым файлом.
- **Запуск из исходников:** `config.json` в папке с `main.py`.

**Файл → Открыть папку с config.json** — открывает эту папку в проводнике.

Если `config.json` отсутствует, он создаётся из `config.example.json` или встроенного шаблона.

---

## Подключение к Home Assistant

**Файл → Подключение…**

- **URL** — например `https://192.168.1.10:8123`.
- **Long-Lived Access Token** — HA → Профиль → создать токен.
- **Проверка SSL** — отключайте только при самоподписанном HTTPS, если понимаете риски.

Кнопка **«Проверить»** проверяет доступ к API.

## Кнопки действий

На главном окне кнопки сгруппированы по **вкладкам** (`button_tabs`). Каждая кнопка задаёт `domain`, `service` и при необходимости `service_data` (в т.ч. `entity_id`).

**Файл → Редактор кнопок…** — вкладки, список кнопок, выбор сущности и сервисов из HA.

### Внешний вид (`ui` в `config.json`)

| Параметр | Смысл |
|----------|--------|
| `button_font_size` | Размер шрифта на кнопках |
| `button_pad_x`, `button_pad_y` | Отступы |
| `columns` | Колонок сетки на вкладке |
| `buttons_per_page` | Кнопок на странице; **0** — все сразу; иначе «Назад / Вперёд» |

Список **`buttons`** дублирует кнопки **первой** вкладки (совместимость).

---

## Панель датчиков

Вверху окна — показания выбранных сущностей, обновление по **`sensor_refresh_seconds`**.

- **Свернуть / развернуть** блок — `ui.sensor_panel_collapsed`.
- Вкладки и оформление — **`sensor_tabs`** (каждая вкладка: `title`, `sensors`, `columns`, `item_layout` (`row` / `column`), размеры шрифтов иконки/имени/значения, `label_width_chars`).

**Файл → Датчики на главной…** — редактор вкладок, сетки и списка сущностей.

Поле **`sensor_panel`** — плоский список для миграции; при сохранении из редактора синхронизируется с **первой** вкладкой `sensor_tabs`.

---

## Трей

При установленных **pystray** и **Pillow**:

- сворачивание в трей при закрытии окна;
- запуск свёрнутым в трей;
- меню в трее: показать, выход.

На Windows доступен пункт **автозапуска** (если включён в сборке).

---

## Обзор `config.json`

| Ключ | Назначение |
|------|------------|
| `ha_url`, `ha_token`, `verify_ssl` | Подключение |
| `button_tabs`, `buttons` | Кнопки и вкладки |
| `sensor_tabs`, `sensor_panel` | Датчики и вкладки |
| `sensor_refresh_seconds` | Интервал опроса |
| `ui` | Вид кнопок, сворачивание панели датчиков |
| `close_to_tray`, `start_minimized` | Поведение окна |

Пример: **`config.example.json`**.

---

## Меню «Файл»

| Пункт | Действие |
|-------|----------|
| Подключение… | URL, токен, SSL |
| Датчики на главной… | Вкладки датчиков, сетка, шрифты |
| Редактор кнопок… | Вкладки и кнопки, внешний вид |
| Перезагрузить из config… | Перечитать настройки |
| Открыть папку с config.json | Папка приложения |
| Выход | Завершение |

## Замечания

- Нужны права токена на вызываемые сервисы и чтение состояний.
- Ошибки сети и HA отображаются в статус-строке и в диалогах.
- Иконки `mdi:…` на панели показываются кратким текстом; эмодзи — если поддерживает шрифт.
